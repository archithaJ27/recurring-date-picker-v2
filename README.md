# 📅 Recurring Date Picker (React + Next.js + Tailwind CSS)

A reusable and intuitive **Recurring Date Picker** component built with **Next.js**, **React**, and **Tailwind CSS**.  
Inspired by the TickTick app, it lets users easily select recurring schedules like **Daily**, **Weekly**, **Monthly**, or **Yearly** and instantly see upcoming dates.

## 🛠️ Tech Stack

- ⚛️ **Next.js 14**
- ⚛️ **React 18**
- 🎨 **Tailwind CSS**
- 🟦 **TypeScript**

---

## ✨ Features

- ✅ Select repeat interval: Daily / Weekly / Monthly / Yearly
- ✅ Dynamically generates the next 10 recurring dates
- ✅ Responsive, clean UI with Tailwind CSS
- ✅ Fully reusable and modular component
- ✅ Built with Next.js app routing
